# Задания учебника (РАЗДЕЛ II, с. 169–185)

Листы с заданиями вырезаны из сканов учебного пособия Лукычёвой Л. И. «Управление организацией»
(файлы `Part1.pdf` и `Part2.pdf` в корне репозитория). Каждый разворот скана содержит две книжные
страницы, поэтому страницы разделены: один лист PDF = одна книжная страница.

## Состав папки

| Файл | Книжные страницы | Чему соответствует |
|---|---|---|
| `ПЗ-01_с.169-170.pdf` | 169–170 | Практическое занятие № 1 «Анализ факторов, критериев и ограничений при принятии управленческого решения» (ситуация ОАО «ИМЗ») → отчёт `П-41_Соловьев_АС_ПЗ-01` |
| `ПЗ-02_с.171-172.pdf` | 171–172 | Практическое занятие № 2 «Принятие управленческого решения с учётом ограничивающих факторов» (А. Н. Петров, табл. II.2.1) → отчёт `ПЗ-02` |
| `ПЗ-03_с.173-175.pdf` | 173–175 | Практическое занятие № 3 «Разработка алгоритма принятия решения» (четыре ситуации, уровни решений); с. 175 — тест → отчёт `ПЗ-03` |
| `ПЗ-04_с.176-178.pdf` | 176–178 | Практическое занятие № 4 «Мозговая атака» (аэропорт «Шереметьево», 8 идей, правила и ранжирование) → отчёт `ПЗ-04` |
| `ПЗ-05_с.179-180.pdf` | 179–180 | Практическое занятие № 5 «Экспертные методы» (задания 1–3); с. 180 — тест → отчёт `ПЗ-05` |
| `ПЗ-07_с.181-183.pdf` | 181–183 | Практическое занятие № 6 учебника «Метод сценариев» (рекламная газета, табл. II.6.1, предприятие по производству мороженого); с. 183 — тест → отчёт `ПЗ-07` |
| `ПЗ-08_с.184-185.pdf` | 184–185 | Практическое занятие № 7 учебника «Пошаговый разбор ситуаций» (Microsoft/Linux, механик, сокращение работника) → отчёт `ПЗ-08` |
| `Все_задания_с.169-185.pdf` | 169–185 | Все перечисленные страницы одним файлом |
| `Превью_PNG/` | — | Те же страницы в виде изображений (`с.169.png` … `с.185.png`), 150 dpi, оттенки серого |

Отчёт `П-41_Соловьев_АС_ПЗ-06_СМ` (семинар по фильму «Собственное мнение») заданием учебника
не является, поэтому страниц в этой папке не имеет.

## Как пересобрать

```bash
python3 tools/extract_tasks.py
```

Скрипт заново вырезает страницы из `Part1.pdf` / `Part2.pdf` и перезаписывает содержимое этой папки.
Соответствие листов скана и книжных страниц: `Part1.pdf`, лист `i` → страницы `2i+2` (слева) и
`2i+3` (справа); `Part2.pdf`, лист `i` → страницы `2i+180` и `2i+181`.
