## 4. Проверка расчётов (выполнена пересчётом)

- Все 9 значений прибыли (3 варианта x 3 сценария) пересчитаны по формуле Π = P1 x P2 x [N x (M/12) x (Ц - S) - З]: совпадают до копейки (в т.ч. -15 600 / -3 173,33 / -8 500 в пессимистике).
- Все 18 значений рентабельности (R и Rож) пересчитаны: совпадают (в т.ч. -13,18% / 5,16% / 15,94% у варианта 3).
- Критерии Вальда и maximax: консерватор -> вариант 2 (max(минимумов) = -3 173,33), рационалист и авантюрист -> вариант 3. Логика верна.
- Разрывы в обосновании выбора: 12 833,33 - 7 920 = 4 913,33; 12 833,33 + 2 640 = 15 473,33 - совпадают.
- Кейс «Вектор-Пак»: E(Π) = 4,075 / 7,475 / 5,950 млн руб. и взвешенные оценки 3,50 / 4,55 / 2,65 пересчитаны - совпадают; вероятности сценариев 0,25 + 0,55 + 0,20 = 1,00.
