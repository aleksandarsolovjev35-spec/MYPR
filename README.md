Каждая работа существует в двух синхронных версиях: **Markdown** (исходник, удобно читать и править)
и **DOCX** (итоговый отчёт с титульным листом для сдачи). Содержание версий совпадает; различается
только оформление титульного листа.

## Структура репозитория

```
П-41_Соловьев_АС_ПЗ-0N.md / .docx      отчёты по работам 1–8
```

### Служебные скрипты (`tools/`)

| Скрипт | Назначение |
|---|---|
| `md2docx.py` | Перенос содержимого `.md` в существующий `.docx` с сохранением оформления и титульного листа: `render(md_path, docx_path)` |
| `fix_titlepages.py` | Приведение титульных листов всех `.docx` к единому виду (год 2026) |
| `make_mindmap_pz04.py` | Генерация интеллект-карты для ПЗ-04 |
| `extract_tasks.py` | Вырезание листов с заданиями из `Part1.pdf` / `Part2.pdf` в папку `Задания_учебника/` |

Для работы скриптов нужны `python-docx`, `pymupdf`, `matplotlib`.

## Проверка работ

Отчёты трижды сверялись со сканами учебника: условия ситуаций и таблицы (II.2.1, II.6.1,
квалификационные характеристики работников), постраничные ссылки на теорию, арифметика всех расчётов
(ожидаемая прибыль и рентабельность по сценариям, веса и взвешенные оценки, коэффициенты
компетентности экспертов, суммы рангов, бюджет), а также соответствие `.md` и `.docx`.
